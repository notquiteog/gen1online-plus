# Optional Wild Skies integration

The room advertises sharedSkies only when a provider exposes the public shared-field, claim-validation and encounter callbacks. Both endpoints negotiate before registration. Sky records use pixel coordinates and independent altitude, separate from ground encounter cells. Each provider keeps its own art, ecology and animation.

The authority filters reserved/consumed identities from snapshots. A grant precedes removal so native pending contacts can enter battle. Replays cannot start another battle. Failed native entry, escape or loss releases the reservation; a win or capture consumes it. Disconnect clears the provider and its session epoch. Localhost packets are deferred to avoid callback re-entry.

The host publishes its current map, provider-supported neighbors and the remote player's map when the provider supports it. A provider may decline an unloaded remote map. This is a coverage limit, not permission for guests to create an independent shared population. Old peers without the capability keep standalone skies.

Other mods remain optional. No sprite archives, imported maps, saves or game data are bundled.
